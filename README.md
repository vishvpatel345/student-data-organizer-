# Student Management System

This is a simple Python program for managing student records.

## Features

- Add student
- Display all students
- Delete student
- Update student age
- Update student subjects
- Display all subjects
- Exit the program

## Information Stored

For each student, the program stores:

- Student ID
- Name
- Age
- Date of Birth
- Grade
- Subjects

## Python Concepts Used

- List
- Set
- Tuple
- Dictionary
- While loop
- For loop
- If-else
- Input and output
- `append()`
- `update()`
- `delete`
- `enumerate()`
